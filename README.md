# Jarvis

Personal conversational AI, built to run locally and think using AJ's own Obsidian
vault as context. Precursor to the Pickup business project (different product, same
underlying tech pattern).

**Start here:** [`JARVIS-BRIEF.md`](./JARVIS-BRIEF.md) — full project brief, read it
before writing any code.

`context/` holds point-in-time reference copies of relevant wiki pages, kept for
offline reading before Obsidian Sync is confirmed working on this machine. They are
snapshots, not live data.

**This repo already has code** (`main.py`, `agent.py`, `memory.py`, `tools/`) from an
earlier prototype — it's adapted, not clean. See the brief's section 2 for exactly
what exists and what needs to change before it's really "Jarvis."
