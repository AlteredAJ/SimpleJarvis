# Local Brain

Local AI frontend + dashboard over AJ's wiki. Runs free on the M5 Mac. Built 2026-05-30. Tabs/board model added 2026-05-31.

**Location:** `~/Claude/local-brain/` (`server.py`, `static/index.html`, `config.json`)
**Auto-starts at login** via LaunchAgent `~/Library/LaunchAgents/com.aj.localbrain.plist` (RunAtLoad + KeepAlive). No manual start needed. Open http://localhost:8788.
**Manual control:** `launchctl unload/load ~/Library/LaunchAgents/com.aj.localbrain.plist`
**Stack:** Python stdlib HTTP server (port 8788) + Ollama (port 11434) + vanilla JS. Needs `certifi` (installed) for HTTPS to Groq.

## Features

- **Home overview:** "DUE SOON" strip from `wiki/Now.md` urgent items, an "Emails to work on next" view (items in the Emails tab), clickable board summary cards (open-item counts per tab), then the rest of the Now.md sections. Done struck through, urgent flagged. Strips markdown `**`/backticks/wikilink brackets.
- **Tabs / board (NEW):** create and delete tabs from the sidebar ("New tab" + hover-× to delete). Each tab is a list; add items inline. Items have a checkbox (done), a pin (feeds AI), a move-to-tab dropdown, and delete. Deleting a tab orphans its items to Unsorted (tab=""), it does not lose them. Data in `board.json`.

- **Chat:** local or free-API model, auto-injects relevant wiki pages (keyword RAG) + pinned board items. Tier picker + status shows which brain answered. Typing indicator.

The model replies in plain language AND appends a single `<actions>[...]</actions>` JSON block on change requests.

Execution uses the existing primitives (`toggle_check`, `toggle_assignment`, `save_assignment_grade`, `add_check_item`, board read/write).

If the touched view (Checklists/Classes/Board) is currently open it auto-refreshes. The AI always confirms in natural language too, so intent is clear even if a match fails.

## Design
Built with `/impeccable` + `/design-motion-principles`. Register: product. Motion weighting: Emil (fast, restrained, sub-200ms, ease-out-quart) primary, Jakub secondary. OKLCH tokens, AA contrast, full prefers-reduced-motion fallback, focus-visible rings, Escape closes modal. Strategy: restrained (tinted-neutral surfaces + one blue accent). ### Animation / 3D layer (NEW 2026-05-31)
AJ asked to bring an animation/3D library list into the design. Local Brain is a vanilla-JS single-page offline app, so most of the list does NOT fit and was deliberately excluded: react-three-fiber / react-spring / Framer Motion (React-only), A-Frame/WebXR (VR), Babylon + PlayCanvas (full game engines), Pixi (2D-game overkill), Barba (multi-page transitions, this is an SPA), Locomotive (fights the fixed grid layout). The tasteful, architecture-compatible subset was adopted:
- **three.js** (r128 UMD) — a subtle ambient particle backdrop. Fixed full-viewport `<canvas id="bg3d">` at `z-index:-1`; `body` is transparent and `html` carries `--bg`, so the canvas is the living background behind the (opaque) sidebar and cards. ~800 accent-tinted points, slow rotation + mouse parallax, additive blend on dark / normal on light, DPR capped at 1.5. Theme-aware (recolors on `data-theme` change via a 1px canvas that reads the OKLCH `--bg`/`--accent`). Honors reduced-motion (single static frame, no rAF) and pauses the loop when the tab is hidden. Falls back to flat `--bg` if WebGL is unavailable.
- **GSAP + ScrollTrigger** (3.12.5 UMD) — staggered card reveal. A MutationObserver on `#panel` re-runs the reveal on every view render; `ScrollTrigger.batch` (scroller = `#panel`) fades cards (`.block, .sec, .cl-card, .tablewrap`) up as they enter, so above-fold cards animate immediately and below-fold ones reveal on scroll. Old triggers are killed each render. Replaced the old CSS panel-enter keyframe re-trigger.
- **Offline preserved:** all three libs are vendored to `static/vendor/` (not CDN). New server route `GET /static/<path>` (`_serve_static`) serves them with a path-traversal guard (resolved path must stay under `STATIC_DIR`).
- Verified 2026-05-31 (Playwright): WebGL context live, canvas sized, cards reveal on scroll, theme toggle recolors backdrop, view-switching re-runs reveal, 0 console errors. The "no external libs" line above no longer holds for the UI — it's now "offline, vendored libs, no network."

### Motion pass 2 — "dashboard feels alive" (NEW 2026-05-31)
Four more motion features layered on the three.js/GSAP base. All reduced-motion guarded, all vendored (added `Flip.min.js` to `static/vendor/`).
- **Hover lift on cards.** Home `.bcard` gets a cursor-tracking 3D tilt + lift (delegated `pointermove`/`pointerout` on `#panel`, max ~5deg, resets on leave; `:active` still presses down). `.cl-card` gets a pure-CSS hover lift + shadow under `@media (prefers-reduced-motion: no-preference)`.
- **Count-up numbers.** On a genuine view switch (keyed off `#title` text, never on in-view re-render), every integer inside `.cl-pct`, `.cl-phase-count`, `.bcard .n`, `.count-pill` tweens 0→target via GSAP `endArray`; `.clbar-fill` widths reset to 0 then grow. `window.__lbCount()` forces a re-run.
- **GSAP Flip on item toggle.** Board/tab `.item` rows carry `data-flip-id="item-<id>"`. The toggle/pin/delete/move handlers now call `flipRender()`: `Flip.getState('#panel .item')` → `renderAll()` → `Flip.from(...)` so rows slide between the open and Done lists (with `onEnter`/`onLeave` fade-scale). Skipped under reduced-motion. `Flip` exposed as `window.__lbFlip`.
- **3D wiki graph hero on Home.** New server route `GET /api/wiki/graph` (`wiki_graph()`) returns `{nodes:[{name,deg}], edges:[{s,t}]}` built from `[[wikilink]]` adjacency between existing pages. Frontend `mountWikiGraph()` renders a force-directed (90-iter repulsion + edge-spring) three.js node graph in a `.wikigraph` hero, own WebGLRenderer + Raycaster: drag to spin, hover shows a page-name label, click navigates (`pageToView()` maps Academics→classes, Checklist→checklists, Housing→apartments, Cars→tab; else opens chat prefilled `Tell me about [[page]]`). Disposes the prior instance on every Home re-render (`wgStop`) — verified single canvas after repeated nav, no leak.
- Verified 2026-05-31 (Playwright): graph endpoint 42 nodes/146 edges, canvas mounts + disposes cleanly, Flip toggles a real board item done→reverted with the row animating, count-up shows intermediate values (`0/0`→`0/1`) and bars grow 0→100%, hover tilt sets/clears transform, 0 console errors or warnings across the run.

- **Grab — TikTok/Reels grabber (NEW 2026-06-18):** paste a TikTok or Reels link and it returns a structured result, the video's content decides the shape (shopping list + prices, setup/how-to guide, recipe, packing list, or a plain summary). Optional free-text prompt steers the output. Fully local + free.
  - **Pipeline** (`~/Claude/local-brain/grabber.py`): `yt-dlp` downloads the clip + caption/metadata → `faster-whisper` (base, CPU int8) transcribes speech → `ffmpeg` pulls ~4 keyframes → the **vision model reads on-screen text overlays** (uses `local_vision_model` from config = `llama3.2-vision`, since `qwen2.5vl:7b` crashes the runner on this box) → `qwen2.5:7b` classifies the clip and extracts a JSON payload (type, title, summary, key_points[], items[], steps[], links[], tags[]). Markdown is rendered deterministically in Python so the 7B model can't mangle formatting.
  - **Types (2026-06-21):** shopping, guide, recipe, **money** (side hustle / passive income / flipping / deals / scholarships / apps that pay → extracts the how-to steps + the apps/sites/tools as items + earnings claim in summary), packing, summary. Every type now also fills a **key_points[]** list (2-6 concrete specifics: tool names, dollar amounts, requirements, deadlines) so even a "summary" clip captures the real substance instead of one vague sentence.
  - **Library priority order (2026-06-21):** categories are sorted by importance, not alphabetically, driven by `grab_priority` in config.json (list, most important first). Currently `["money","guide","recipe","shopping","packing","summary"]` — jobs/money on top per AJ. The top category gets a red "priority" badge. Change one config line + reload to re-rank when focus shifts. Server returns the order via `/api/grabs` `{grabs, priority}`; UI falls back to a built-in order if absent.
  - **Reclassify without re-download:** the `.json` sidecar stores the full `signals` (transcript + overlays), so old grabs can be re-run through `grabber.structure()` + `grabber.render()` and rewritten in place without touching `yt-dlp`. Used this to retro-fit the money type + key_points onto the first 20-reel batch (skip `type==recipe` during reclassify or you wipe the enriched prices).
  - **Link safety:** only URLs that literally appear in the caption/transcript are kept; invented profile/store links are dropped in code (the model hallucinated a TikTok profile URL during testing).
  - **Login-gated clips / cookies (2026-06-21):** `download()` tries **anonymously first** (public clips carry no identity), and only on failure falls back to reading **live login cookies** from a local browser, set by `cookies_from_browser` in config.json (= `chrome`; `cookies_file` is an optional Netscape cookies.txt fallback). Never stores a password; cookies are read at runtime via yt-dlp's `cookiesfrombrowser` and sent only to the video host.
